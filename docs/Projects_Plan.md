# SaaS Subscription & Billing Analytics Platform

## Objective

Build a production-oriented SaaS subscription and billing backend using
Django and PostgreSQL, with Advanced SQL as the primary technical focus.

## Primary Goals

- Design a normalized relational database
- Build the backend using Django
- Learn PostgreSQL through implementation
- Develop Advanced SQL skills
- Practice SQL interview problems using project data
- Understand query optimization and database performance

## Secondary Goal

Learn basic developer-level testing for backend functionality.

## Core Technologies

- Python
- Django
- PostgreSQL
- SQL
- Git/GitHub
